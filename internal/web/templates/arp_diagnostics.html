What this shows

The exact contents of the kernel's ARP table (/proc/net/arp) right now, and whether each entry's interface matches a configured LAN segment. A device only shows up as "discovered" on the dashboard if it appears below and its Interface column exactly matches one of your configured segments' Interface field - a mismatch there (extra space, wrong name) is the most common reason something's missing.
